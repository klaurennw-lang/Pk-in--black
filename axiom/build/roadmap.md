# Build Roadmap — 12 weeks

The plan to go from zero (today) to first paying client (week 12). Built for one founder + light contractor support. Each week has a single primary outcome.

**Today's date for the plan:** 2026-04-25 (adjust if you start later)
**Target first paying client signed:** 2026-07-18 (week 12)

---

## Phase 1 — Foundation (Weeks 1–4): build the dogfood instance

Before selling, prove the system works by running it on the founder's own 139K-follower IG channel as case study #1.

### Week 1 (Apr 27 – May 3) — Brand voice doc + voice scorer for self
**Primary outcome:** Filled-in `brand-voice-template.md` for Pk-in--black IG channel. Voice scorer trained on founder's last 100 posts.
- [ ] Pull last 100 IG posts (transcripts + captions) into a corpus
- [ ] Fill out brand voice template (every section, no placeholders left)
- [ ] Build v1 voice scorer (simple LLM-as-judge with rubric, log scores per piece)
- [ ] Validate scorer on held-out set (10 posts)
- [ ] Document signature phrases, banned phrases, hook patterns that worked

### Week 2 (May 4 – 10) — Strategist + Researcher running on self
**Primary outcome:** First weekly calendar + research briefs generated by agents and shipped on the founder's own channel.
- [ ] Set up Strategist agent (system prompt, inputs, weekly cron)
- [ ] Set up Researcher agent (web search + Perplexity, output schema)
- [ ] Generate first 14-day calendar
- [ ] Generate research briefs for week 1 of calendar
- [ ] Founder uses outputs to shoot/post (manually); log which suggestions were used vs. ignored

### Week 3 (May 11 – 17) — Scriptwriter running on self
**Primary outcome:** Scripts for next week's IG content generated by agent, in voice, ready to shoot.
- [ ] Set up Scriptwriter agent
- [ ] Run voice scorer on every output; reject anything <85
- [ ] Founder shoots 5 pieces from agent scripts; logs voice fidelity in production
- [ ] Audit: did scripts feel like founder's? Where did they miss?
- [ ] Tighten prompts based on audit

### Week 4 (May 18 – 24) — Producer + Editor templates (Remotion baseline)
**Primary outcome:** A repeatable Remotion-based template stack that produces intros, outros, lower-thirds, and short-form caption videos for the founder's channel.
- [ ] Build Remotion compositions: intro, outro, lower-third, caption template, thumbnail template
- [ ] Wire to Lambda for cloud rendering
- [ ] Generate first templated short from a script
- [ ] Document: what's templated vs. what still requires CapCut handwork
- [ ] Asset library schema in place; ingest founder's existing brand assets

## Phase 2 — Productize (Weeks 5–8): turn the dogfood into a sellable service

### Week 5 (May 25 – 31) — Distributor + analytics plumbing
**Primary outcome:** Posts auto-schedule across IG, TikTok, X for founder's channel; analytics flowing into a single events DB.
- [ ] Distributor agent: cross-platform format conversion via FFmpeg
- [ ] Buffer or Publer integration for scheduling (start there; native APIs later)
- [ ] Set up Postgres events DB with `post`, `asset`, `script`, `metric` tables
- [ ] Pull IG/TikTok/YT analytics into DB nightly
- [ ] Verify cross-platform reach data for past 30 days of founder content

### Week 6 (Jun 1 – 7) — Analyst v1 + dashboard
**Primary outcome:** First weekly analyst report generated and reviewed; basic Metabase dashboard live.
- [ ] Analyst agent: weekly report template, runs Sundays
- [ ] Compute baselines for founder's channel (median per platform per format)
- [ ] Stand up Metabase on a small VPS; connect to events DB
- [ ] Build core charts: weekly performance, top performers, baseline-vs-actual
- [ ] Deliver first analyst report on founder's content; iterate format

### Week 7 (Jun 8 – 14) — Sales assets + landing page
**Primary outcome:** Public-facing sales surface ready: landing page, case study, calendar booking link.
- [ ] Build axiom.{tld} landing page (one page, three tiers, CTA: book discovery call)
- [ ] Write case study using founder's channel as proof
- [ ] Set up Calendly with discovery-call template (45 min)
- [ ] Set up CRM (HubSpot Free or Notion table) with pipeline stages
- [ ] Email sequence templates: post-discovery, post-proposal, follow-up

### Week 8 (Jun 15 – 21) — Onboarding sprint dry run
**Primary outcome:** Run a full onboarding sprint on a fictional client (or a friendly volunteer at zero cost) to validate the SOP.
- [ ] Recruit 1 friendly volunteer creator for free 2-week sprint
- [ ] Execute every checklist item from `onboarding-sprint.md`
- [ ] Time every step; identify what's slower than budgeted
- [ ] Capture every "we should have a template for that" moment
- [ ] Produce sprint deliverables; get volunteer feedback
- [ ] Update SOPs and templates with everything learned

## Phase 3 — Sell (Weeks 9–12): land first paying client

### Week 9 (Jun 22 – 28) — Outbound prep
**Primary outcome:** 50 qualified target prospects identified and researched; outbound sequences ready.
- [ ] Define ICP (ideal client profile) sharply: niche, follower range, business behind channel, signal of pain
- [ ] Build prospect list of 50 (use founder's network first, then LinkedIn Sales Navigator / Apollo)
- [ ] Research each: what they post, what their bottleneck looks like, who they are as a person
- [ ] Write personalized first-touch DMs/emails (no templates that ignore the person)
- [ ] Set up tracking: pipeline stage per prospect

### Week 10 (Jun 29 – Jul 5) — Outbound + content marketing
**Primary outcome:** 50 first-touches sent. 5+ discovery calls booked.
- [ ] Send personalized outreach (10/day, M-F)
- [ ] Post 3 pieces on founder's IG showcasing the system (meta-content)
- [ ] Engage in 5 communities where ICP hangs out (no pitch; provide value)
- [ ] Run discovery calls as they get booked

### Week 11 (Jul 6 – 12) — Discovery calls + proposals
**Primary outcome:** 8+ discovery calls held, 3+ proposals out, 1+ verbal yes.
- [ ] Hold every booked discovery call
- [ ] Send proposals within 24 hours of qualifying calls
- [ ] Follow up at +48hr, +5 day, +14 day intervals
- [ ] Capture every objection in `decision-log.md`; update objection handling doc

### Week 12 (Jul 13 – 18) — Close + onboard
**Primary outcome:** First paying client signed; onboarding sprint scheduled to start week 13.
- [ ] Close first deal (Foundation or Studio tier)
- [ ] Send contract, collect onboarding fee
- [ ] Schedule sprint kickoff for the following Monday
- [ ] Update `state.md` to reflect: first client signed, capacity remaining, next priorities

## After week 12 — what's next (preview)

- **Weeks 13–14:** Execute first real onboarding sprint. Time everything; refine templates.
- **Weeks 15–18:** First retainer month. Track every SLA metric. Aim for 100% on-time delivery to build proof.
- **Weeks 19–24:** Hire #1 (strategist or editor-supervisor depending on tier mix sold). Sign clients 2–4.
- **Months 6–12:** Scale to 5–8 clients. Build dashboard product. Codify everything that's still in the founder's head.

## Risks & mitigations

| Risk                                            | Mitigation                                                      |
| ----------------------------------------------- | --------------------------------------------------------------- |
| Founder gets pulled into delivery instead of selling | Hire editor-supervisor on contract by week 8 to free founder for sales |
| Voice scorer doesn't generalize beyond founder  | Test on volunteer client in week 8; calibrate before paid clients |
| Tooling cost overruns                           | Track API spend weekly from day 1; cap monthly spend per agent  |
| First client is wrong-fit and burns reputation  | Apply disqualification rules from `discovery-call-script.md` aggressively |
| Sprint runs over allotted hours                 | Time every task; if a sprint runs >120% of budget, stop selling and template the gap |

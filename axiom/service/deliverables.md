# Deliverables Contract

This is what the client receives. It's the document we hand over, week one. If it's not on this list, it's out of scope.

---

## Foundation tier

### Weekly deliverables

| Day        | Deliverable                              | Format                |
| ---------- | ---------------------------------------- | --------------------- |
| Mon 12pm   | 14-day content calendar (refreshed)      | Notion + PDF export   |
| Tue EOD    | 2–3 ready-to-shoot scripts               | Google Docs           |
| Thu EOD    | 2–3 ready-to-shoot scripts               | Google Docs           |
| Fri EOD    | Hook bank: 25 hooks scored 1–5 in voice  | Notion table          |
| Sun 9pm    | Trend brief: 1 page, 3 angles            | Google Doc            |

### Monthly deliverables

| When           | Deliverable                                        |
| -------------- | -------------------------------------------------- |
| 1st of month   | Brand voice doc review + update                    |
| 1st of month   | Competitor scan refresh (top 5 in niche)           |
| 15th of month  | 30-min strategy call with assigned strategist      |

### Quality bar
- All scripts pass voice-match test (≥80% on internal voice scorer)
- Hooks tested against last 90 days of client's top performers
- Trend briefs cite ≥3 sources

## Studio tier (everything in Foundation, plus:)

### Weekly deliverables

| Day        | Deliverable                                                      |
| ---------- | ---------------------------------------------------------------- |
| Mon EOD    | Production schedule for the week (what's shooting, what's editing) |
| Wed EOD    | First-pass edits of long-form content delivered                  |
| Thu EOD    | Final cuts + captions + thumbnails ready for client review       |
| Fri 4pm    | 15-min review call (or async approval in Notion)                 |
| Fri–Sun    | Posts auto-scheduled across all connected platforms              |

### Per-piece deliverables (long-form, up to 2/week)
- Polished cut with intro/outro
- Burned-in or platform-native captions (client's choice)
- Thumbnail (3 variants for A/B if applicable)
- Description, title, tags optimized per platform
- Chapters/timestamps for YouTube
- Music + SFX bed where appropriate

### Per-piece deliverables (short-form, up to 10/week)
- Vertical format (1080×1920)
- Captions (animated, brand-styled)
- Hook in first 1.2 seconds
- Hashtag/keyword set per platform
- Posted to: Reels, Shorts, TikTok, X, LinkedIn (where applicable)

### Quality bar
- Long-form: ≤24hr revision turnaround on flagged issues
- Short-form: First frame test passes (would you stop scrolling?)
- All captions: 99%+ accuracy after human review
- Thumbnails: pass click-likelihood scorer ≥7/10

| 9am ET       | Comment queue triaged (lead/fan/troll/complaint/op)      |

### Weekly deliverables

| Day        | Deliverable                                              |
| ---------- | -------------------------------------------------------- |
| Sun 9pm    | Analyst report: what worked, what didn't, why, next moves |
| Sun 9pm    | Dashboard refresh (auto)                                 |
| Sun 9pm    | Recommended content adjustments for next week            |

### Monthly deliverables

| When         | Deliverable                                                  |
| ------------ | ------------------------------------------------------------ |
| 1st          | Executive review with founder (60 min)                       |
| 1st          | Quarterly roadmap update                                     |
| 15th         | Brand-deal pipeline review (if add-on active)                |

### Quality bar
- DM response: brand voice match ≥90%, no off-brand replies ever

- Dashboard uptime: 99.5%
- Analyst report: actionable (every recommendation has a "do this" verb)

## Out of scope (always)

These are not included at any tier. Don't quietly do them or you train the client to expect them free.

- Live event coverage / on-location shooting
- Custom software development beyond the dashboard
- Email marketing / newsletter writing (separate offering)
- PR / press outreach
- Talent management / contract negotiation (Empire add-on, not base)
- Crisis communication
- Anything illegal, deceptive, or off-brand under any circumstances

---

## Service Level Agreement

| Metric                                  | Target              |
| --------------------------------------- | ------------------- |
| Weekly delivery on-time rate            | ≥98%                |
| Revision turnaround                     | ≤24 hours           |
| Client communication response time      | ≤4 hours, business  |
| Brand voice score (internal)            | ≥85%                |
| Client NPS (quarterly survey)           | ≥50                 |
| Churn (annualized)                      | ≤15%                |

If Axiom misses two consecutive weeks of on-time delivery, the client gets that month free. This makes the SLA real.
